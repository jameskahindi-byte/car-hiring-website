

# MBR Drive - Car Hiring Website

## About
MBR Drive is a simple car hiring website built using HTML, CSS, and JavaScript. It allows users to explore available cars and fill out a booking form.

## Features
- Home page for MBR Drive
- Cars page displaying available vehicles and daily rental prices
- Booking form for customer details
- Automatic booking cost calculator
- Browser storage for demonstration bookings
- Responsive design with a red-and-black theme

## Available Cars
- Chevrolet Camaro - KSh 12,000 per day
- Mercedes-Benz - KSh 10,000 per day
- Family SUV - KSh 8,000 per day
- Economy Car - KSh 4,000 per day

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## Project Files
- `index.html` - Home page
- `cars.html` - Available cars
- `bookings.html` - Booking form
- `style.css` - Website styling
- `script.js` - Booking calculator and form functionality

## How to Run
1. Open the website using its published GitHub Pages link.
2. Navigate to the Our Cars page to view available vehicles.
3. Open the Bookings page to select a car and enter booking details.
4. The estimated rental cost is calculated automatically.

## Note
This is a learning project. Bookings are stored in the visitor's browser and are not sent to a real car rental company.
